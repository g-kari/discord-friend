# Discord Friend

Cloudflare Workers / Containers と VOICEVOX を使う、開発中の Discord テキスト読み上げサービスです。旧 Go 版は比較用に残しています。

既定では Bot と HTTP 受付は無効、両コンテナの上限は 0 です。2026-10-03 の限定試験で実際の読み上げを確認しましたが、それ以降の実装や現在の稼働状態を保証するものではありません。
